# 📝 Notes App

A simple and responsive Notes App built with React and Tailwind CSS.

## 🚀 Features

- Add notes
- Delete notes
- Form validation
- Prevent blank notes
- Responsive card layout
- Clean and simple UI

## 🛠️ Technologies Used

- React
- JavaScript
- Tailwind CSS
- Vite
- Lucide React
